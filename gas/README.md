# ☁️ StockReport - Google Apps Script (GAS) 연동 가이드

본 매뉴얼은 **StockReport** 프로그램의 구글 앱스 스크립트(GAS) 버전을 구글 드라이브 및 스프레드시트에 등록하여 설치 및 사용하는 방법을 설명합니다.

---

## ✨ 1. 주요 기능

- 📥 **독립적 리포트 다운로드 수집**: 네이버 증권 등 주요 리포트 웹데이터를 구글 드라이브 지정 폴더로 수집/저장
- 🤖 **독립적 AI 분석 및 요약**: Google Gemini API (`gemini-2.5-flash`)를 연동하여 수집된 리포트의 핵심 종목, 투자의견, 시장 방향성 자동 요약 리포트 생성 (`AI_Report_Summary_YYYY-MM-DD.md`)
- 🎯 **체크박스 기능 분리**: 모달 UI에서 원하는 기능만 체크하여 개별 또는 동시 실행
- ⏱️ **스케줄 트리거 자동화**: 1시간/하루 단위 주기적 백그라운드 자동 실행
- 📱 **텔레그램 알림**: 다운로드 결과 및 AI 분석 요약 본문 텔레그램 전송

---

## 🛠️ 2. 설치 방법

1. [구글 드라이브](https://drive.google.com/) 접속 후 새 **구글 스프레드시트** 생성
2. 상단 메뉴에서 `확장 프로그램` > `Apps Script` 클릭
3. 편집기 내 기존 코드(`myFunction`)를 모두 삭제하고, [`gas/Code.gs`](file:///c:/dev/Antigravity/StockReport/gas/Code.gs) 파일의 전체 내용을 복사하여 붙여넣기
4. `Ctrl + S` 키를 눌러 저장 후 스프레드시트 탭으로 돌아가 새로고침 (`F5`)
5. 상단에 **`📊 증권 리포트 수집기`** 커스텀 메뉴가 나타나는지 확인

---

## ⚙️ 3. 기능 선택 및 환경 설정

1. 스프레드시트 상단 메뉴: **`📊 증권 리포트 수집기`** > **`⚙️ 기능 설정 (체크박스 & API 키)`** 클릭
2. 대화상자가 열리면 원하는 기능을 체크박스로 선택:
   - `[✓] 📥 증권사 리포트 수집 (구글 드라이브 저장)`
   - `[✓] 🤖 AI 리포트 분석 및 요약 (Gemini API)`
3. 필요한 API 키 및 ID 입력:
   - **Google Gemini API Key**: [Google AI Studio](https://aistudio.google.com/)에서 생성한 키 입력
   - **Google Drive 폴더 ID**: 수집한 PDF 및 요약파일을 저장할 구글 드라이브 폴더의 URL 주소 끝 ID (미입력 시 루트 폴더에 저장)
   - **텔레그램 Bot Token & Chat ID**: 알림을 받을 텔레그램 정보
4. `💾 설정 저장하기` 클릭

---

## 🚀 4. 실행 및 스케줄링

- **즉시 실행**: **`📊 증권 리포트 수집기`** > **`▶ 작업 즉시 실행`**
- **스케줄 등록**: **`📊 증권 리포트 수집기`** > **`⏱️ 1시간 반복 스케줄 등록`**
- **스케줄 삭제**: **`📊 증권 리포트 수집기`** > **`🛑 등록된 스케줄 삭제`**

---

## 🔄 5. 기존 배포 전면 삭제 및 신규 재배포 절차

기능이 변경된 최신 버전으로 완전히 새로 배포하려면 아래 순서대로 진행합니다.

1. **기존 스케줄 트리거 삭제**:
   - 구글 스프레드시트 상단 메뉴: **`📊 증권 리포트 수집기`** > **`🛑 등록된 스케줄 삭제`** 클릭
2. **Apps Script 편집기 접속**:
   - 상단 메뉴 `확장 프로그램` > `Apps Script` 클릭
3. **기존 배포 삭제 (Undeploy / Archive)**:
   - Apps Script 우측 상단 **`배포`** 버튼 클릭 > **`배포 관리`** 선택
   - 등록되어 있는 기존 배포 항목 옆의 **휴지통 아이콘 (삭제 / 보관)**을 클릭하여 모두 삭제 후 `완료` 클릭
4. **최신 소스코드 적용**:
   - `Code.gs` 편집창에 [`gas/Code.gs`](file:///c:/dev/Antigravity/StockReport/gas/Code.gs) 코드 전체를 새로 복사하여 덮어쓰기 (`Ctrl + S` 저장)
   - `appsscript.json`이 필요한 경우 [`gas/appsscript.json`](file:///c:/dev/Antigravity/StockReport/gas/appsscript.json) 내용 반영
5. **신규 배포 생성**:
   - 우측 상단 **`배포`** > **`새 배포`** 클릭
   - 유형 선택 (톱니바퀴) > **`웹 앱`** 또는 **`라이브러리/트리거`** 선택 후 `배포` 클릭
6. **신규 기능 체크박스 설정 & 스케줄 등록**:
   - 스프레드시트 탭으로 이동 (`F5` 새로고침)
   - **`📊 증권 리포트 수집기`** > **`⚙️ 기능 설정`**에서 `📥 수집` / `🤖 AI 요약` 체크박스 설정 저장
   - **`📊 증권 리포트 수집기`** > **`⏱️ 1시간 반복 스케줄 등록`** 클릭하여 신규 트리거 활성화
